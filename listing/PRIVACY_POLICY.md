# Privacy Policy — DocVault

**Last updated:** May 23, 2026

Applies to **DocVault** GitHub App and **DocVault Documentation Generator** Action.

## Summary

DocVault analyzes repositories you connect via GitHub Actions or App installation. AI processing uses the **Cursor SDK**. We do not sell your source code.

## Data processed

| Data | Purpose | Retained |
|------|---------|----------|
| Repository contents | Documentation generation | No — processed in CI/Cursor |
| `CURSOR_API_KEY` | SDK auth | No — your GitHub Secrets |
| Org/repo metadata | PR comments, billing | Minimal (App backend) |

## Third parties

- **GitHub** — hosting, Marketplace
- **Cursor** — AI processing ([privacy](https://cursor.com/privacy))
